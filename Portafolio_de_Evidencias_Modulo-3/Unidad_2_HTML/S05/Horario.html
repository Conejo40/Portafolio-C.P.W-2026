Como entregar una práctica

  1. Traer los cambios con un git pull
  2. Crear una rama para la práctica con git switch -c "nombre de la rama"
  3. Trabajar con commits atómicos
  4. subir la rama con git push
  5. Abrir un pull request con GitHub
  6. Revisar y fusionar el pull request
  7. Volver a la rama principal(main)
  8. Eliminar la rama de la práctica con git branch -d "nombre de la rama"

Glosario git

Commit:
Instantánea permanente del proyecto en un momento dado
Rama:
Línea de trabajo paralela que no afecta a la rama principal(main)
Pull request:
Solicitud de revisión para incorporar una rama
